## 1. Objectives & Threat Model
Operational artifacts generated by LLMs (ICE scoring calculators, growth playbook matrices, Ship 30 cheat sheets) contain untrusted HTML markup. If rendered directly in the application's top-level DOM, malicious prompts or compromised outputs could trigger Cross-Site Scripting (XSS), cookie/token exfiltration, or DOM manipulation.

The objective of Stage 13 is to implement:
1. **Multi-Stage Sanitization**: Bleach attribute whitelisting, CSS sanitization, and automated regex purging of executable `<script>` and `<style>` blocks.
2. **Standalone HTML Document Wrapping**: Transforming sanitized fragments into complete, responsive HTML5 documents styled according to `DESIGN.md` (Deep Slate `#0A0E17`, Electric Emerald `#10B981`, Plus Jakarta Sans / Inter typography).
3. **Strict Content Security Policy (CSP)**: `default-src 'none'; style-src 'unsafe-inline' https://cdn.tailwindcss.com https://fonts.googleapis.com; font-src https://fonts.gstatic.com data:; img-src data: https:; script-src 'unsafe-inline' https://cdn.tailwindcss.com; frame-ancestors 'self'; base-uri 'none'; form-action 'none';`.
4. **Sandboxed Iframe Delivery**: Exposing `GET /api/v1/artifacts/{artifact_id}/iframe` returning `HTMLResponse` with strict security headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: no-referrer`, `Cache-Control: no-cache, no-store, must-revalidate`).
5. **Origin Isolation**: Front-end Growth Canvas renders artifacts inside `<iframe sandbox="allow-scripts">` without `allow-same-origin`, rendering them in an opaque unique origin with zero access to the parent application's cookies, local storage, or DOM.

## 2. Implementation Details

### A. Renderer Service (`backend/app/services/artifact_renderer.py`)
- `get_sandbox_security_headers()`: Produces headers enforcing CSP, anti-sniffing, framing controls, and cache protection.
- `wrap_artifact_html(title, artifact_type, sanitized_content, created_at)`:
  - Generates HTML5 document with dark theme reset (`#0A0E17`).
  - Embeds Google Fonts (`Inter`, `Plus Jakarta Sans`, `JetBrains Mono`) and Tailwind configuration.
  - Employs Electric Emerald badges, scrollbars, and range slider accent colors.
  - Includes header card with artifact type badge, title, live sandbox indicator, and UTC timestamp.
  - Features an Epistemic Sandbox security footer confirming Bleach verification and strict CSP.
- `render_sandboxed_artifact(artifact: ArtifactModel)`: Formats database model into the sandboxed document, handling fallback for empty content.

### B. Route Integration (`backend/app/api/routes.py`)
- Added endpoint `GET /api/v1/artifacts/{artifact_id}/iframe`:
  - Returns `HTMLResponse` with HTTP 200 and security headers.
  - Returns structured HTTP 404 if the artifact does not exist.

### C. Defense-in-Depth Sanitization (`backend/app/agents/orchestrator.py`)
- Enhanced `sanitize_artifact_content`:
  - Strips `<script...` and `<style...` blocks completely via regular expressions before passing to Bleach.
  - Enforces `ALLOWED_HTML_TAGS` and `ALLOWED_HTML_ATTRS`.
  - Runs `bleach.css_sanitizer.CSSSanitizer()` to prevent CSS-based expression injection.
